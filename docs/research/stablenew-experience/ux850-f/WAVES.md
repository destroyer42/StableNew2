# Prioritized waves and decision economics

These are dependency horizons, not dates, effort-day estimates, ROI or an implementation authorization. Candidate priorities use current source mechanisms and explicit uncertainty. Operator counts, recurrence/task denominators, maintenance cost and saved time are **unmeasured**. Ranking can change after Q0 task evidence or new source findings.

## Noncompensatory entry gates

1. A verified unmitigated security/data-integrity/process-ownership threat stops discretionary redesign for owner disposition. No such new acute threat was established here. The localized Load replacement gap is a source-confirmed draft-protection candidate with unobserved incidence, not an invented production incident.
2. Never trade canonical job/process ownership, original evidence, unknown-POST no-retry or user-data safety against an attractiveness score. A candidate violating them is rejected, not discounted.
3. Unresolved material policy gates hold the dependent slice. They do not prevent diagnosis, read-only presentation or unrelated bounded outcomes. Every functional package requires fresh owner selection, exact-base discovery and current validation; research acceptance grants none of that authority.

## First-tranche alternatives and sensitivity

**No code:** manual Save before Load plus a documented warning avoids some loss at low cost but depends on memory and cannot make Cancel safe. **Diagnosis first:** authorized synthetic Windows reproduction confirms the path but adds setup cost; it is appropriate if dirty-state coverage or production callback applicability has drifted. **Bounded implementation P1:** closes the known handler omission with the existing confirmation idiom and no persistent semantics; recommended after owner selection and a future focused deterministic reproducer. **Full recovery store:** adds durability/retention/conflict/security choices and is held at G1.

If source drift adds an effective Load guard, remove P1 rather than refactor it for symmetry. If a verified higher-severity failure appears, it precedes P1. If operator evidence identifies blocked Learning or Motion as the urgent objective, select P4/P5 after explicit owner reprioritization. No unknown operator benefit justifies a rewrite by default.
