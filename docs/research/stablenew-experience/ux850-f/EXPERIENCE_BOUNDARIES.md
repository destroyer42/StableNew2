# Proposed final information architecture and experience boundaries

“Final” is this program's proposed target boundary, not an adopted navigation migration. Retain [B N1](../ux850-b/NAVIGATION.md) and [C's presentation specifications](../ux850-c/README.md). N2's session-only guide remains a falsifiable alternative if task evidence shows ordinary routes are difficult to discover. A toolkit move or a tenth Library destination needs a separate product/architecture decision; no current evidence justifies either as a prerequisite.

The notebook owns selection. Preserve the nine creation/persistence IDs and order: `prompt, pipeline, learning, review, photo_optimize, movie_clips, character_training, svd, video_workflow`; default `pipeline`. Preserve known-ID-first restoration, numeric fallback only when ID is absent/non-string, unknown string to normal default, legacy index writing, failed-tab placeholders, native-strip fallback and Ctrl+Tab/Ctrl+PageUp/PageDown. Task groups are presentation, not new state owners.

## Handoffs and concurrent work

Reuse [B H1–H10](../ux850-b/HANDOFFS.md) and [D draft/submission boundaries](../ux850-d/DRAFT_SUBMISSION_CONTRACTS.md). Preserve source identity, destination draft/revision, executable Preview and admitted IDs separately. Existing guarded routes stay guarded. Proposed universal replace/cancel rollback is not universally implemented and is not smuggled into P3/P5. A missing incoming-work guard can be reported; adding one requires an explicit destination-specific consent contract.

An async completion must match current request/draft/lifetime and dispatch widget changes on the GUI thread. Hidden content never loads through an inspector/thumbnail/detached bypass. Selecting a route never submits, promotes, saves or cancels jobs. Returning preserves valid in-session query/selection; cross-restart browse restoration is not promised. Submitted work continues under JobService/repository ownership when a tab or draft changes.

Use C's wrapping labels, natural-height controls, fit-driven stack/reflow, vertical scrolling, advanced-value summaries and focus reveal. Preserve advanced routes rather than hiding complexity that is already active. P6 diagnoses real client geometry/keyboard/UIA gaps at the future exact SHA; prototypes and old screenshots cannot justify a production defect claim.
