# Security, privacy and qualification gates

This is a research threat/qualification boundary review, **not independent security sign-off or a permission to execute**. No runtime, model, installation, GPU, firewall, privileged interpreter, backend or qualification ledger was changed or probed. Source identity is E base; E30–E39/E44–E48 are indexed in [SOURCE_INDEX.md](SOURCE_INDEX.md).

## Current Offline AI Assist boundary

Production `AiAssistIntegration` constructs the existing service with `allow_candidate=False` and `strict_offline=True`, reads pinned manifests and canonical queue activity, and starts no model/process at construction. The checked-in runtime manifest has no builds; all four checked-in model entries are unqualified candidates. This is evidence of the **shipped registration**, not a census of installed/staged user files. Current source/UI requires qualification and integrity before Suggest can run; physical suggestion quality remains NOT TESTED under living authority.

Admission checks installation, outbound restriction attestation, generation/quarantine activity and finite memory observations. Unknown readers fail closed. The owned CPU-only request yields to generation; request cancellation cannot cancel a production job. The guard observes queue state and has a bounded polling residual, not an atomic lease preventing any overlap. Existing numerical memory/watch limits are source policy in E31 and `AI_ASSIST.md` §4, not fresh capacity/safety measurements or proposed campaign thresholds.

The runtime uses a bounded owned subprocess, pinned bytes/provenance and closed arguments/environment; strict offline means an **operator attestation**, not application-verified firewall denial. Fast size/mtime verification is not a fresh cryptographic check against same-stat tampering. Actual binary behavior, OS containment, network/file observation and teardown need identity-applicable qualification. Hermetic tests and a past canary do not establish real-model egress safety. Prompt scratch cleanup can be delayed by crash/locked files; event logs are restricted to content-free codes/digests/counts. These limits must remain visible in any future privacy claim.

Prompt suggestions accept only typed schema-valid, protected-token/closed-list output, with source/context revalidation at explicit acceptance. This constrains accepted structure and action authority; it does not prove factual accuracy, semantic fidelity or immunity to all prompt injection. No AI output becomes an executable job, and no AI module gains queue/runner/backend imports. The Learning opaque summary is not consumed by production AI; any later caller must stay outside the restricted package and freshly resolve candidates before normal operator actions.

## Conditional trust gates

| Future surface | Gate / negative case that must be resolved in its own package | Safe present route |
|---|---|---|
| Model/evaluator supply chain | Exact publisher/packager/converter/runtime/weight hashes, license and dependencies; unknown bytes or a remote-code requirement refuse. Existing pins are not a new license/security opinion | Current deterministic policy and manual review; no install/download |
| Vision/media inputs | Bounded decode, dimensions/frame counts, decompression/resource/path containment, cancellation, stale source identity and error states; malformed media must not become a negative quality label | Current supported inspector/contact-sheet/clip paths with their own bounds; no general trust inheritance |
| Image screening | Independent quality/calibration, false negatives and human sampling; failure/abstention remains unknown; screening cannot hide/delete canonical outputs or create human labels | Operator review/technical integrity checks |
| Prompt/evidence injection | Treat notes, catalog text, imported claims, OCR/captions and model output as data. Strict schema/closed candidate validation, no shell/path/network authority from output | Token-only summary, deterministic next actions and explicit ordinary workflow |
| General research packages | Schema/version/size/path/archive/link validation, source namespace, integrity, provenance and collision/dependence preview before selection. Hash-valid malicious or scientifically irrelevant content stays untrusted | Existing narrowly reviewed advisory catalog; original evidence preserved |
| Consequential evidence import | Preserve original source/applicability, conflicting findings and dependent datasets; imported observation cannot impersonate local execution or acquire local qualification | Attributed hypotheses and explicit targeted validation proposals |
| Training/personalization | Separate consent/data-use/retention/security contract and validated release process. Offline AI Assist v1 prohibits training-data capture/fine-tuning; E cannot repurpose its logs | Human ratings stay in native Learning stores; no training/export |
| Campaign repair and routing | G3/G4 approval applicability, current canonical authority and exact IDs; unowned processes/ambiguous dispatch never repaired or replayed automatically | Current explicit job controls and action-required diagnostics |
| Privileged/physical qualification | Exact authorized frozen plan, protected capture, canary/observation completeness, read-root policy, lifecycle proof and owner acceptance; failed/uncertain proof holds subsequent work | Documentation and deterministic contracts only |

Catalog import specifically merges by record ID with imported entries winning and publishes a new selected revision. Previous snapshots remain. Schema and digest checks establish bounded format/content identity, not collision consent, source reliability or scientific independence. This is an existing G5/G6 gap rather than a newly verified irreversible data-loss event; no destructive recommendation or threat clearance follows from E.

No new material unmitigated threat requiring emergency runtime action was verified within this bounded static review. This is limited negative evidence: full parser/supply-chain/OS/process/hardware audits and separate reviewer acceptance remain unavailable. Any future recommendation to **enable now** that requires missing proof would stop at the named gate. E instead classifies those capabilities as qualification-dependent, experimental or blocked.
