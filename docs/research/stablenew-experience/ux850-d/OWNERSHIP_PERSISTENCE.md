# Ownership and persistence matrix

All current observations are at [D's source cut](SOURCE_INDEX.md). **I** = editable/durable intent; **S** = immutable executable or evidence snapshot; **L** = authoritative mutable job lifecycle; **P** = derived/GUI projection. A saved document is not permission to execute. A metadata store is never an alternative job repository. Logical paths are code-defined examples; no operator store was opened.

## Finite proposed durable-type register

These are **logical design candidates**, not production classes, schemas or accepted stores. Each row names exactly one metadata authority. References into another authority are identifiers/hashes, never copied mutable truth. Schema/path/API choices remain gated; a new metadata namespace can still require an explicit migration/security review.

| Proposed durable type | Sole candidate metadata authority | Identity / allowed payload | Approval gate before implementation |
|---|---|---|---|
| P1 WorkspaceDraftRecovery | **UIStateStore extension** | Versioned draft ID/revision, workspace/source kind, base saved revision, edited fields and explicit media refs; no saved approval/job state | G1: durability/retention/sensitive fields/conflicts/error visibility; schema/migration decision |
| P2 ModelLockPreferences | **GenerationProfileStore extension** | Exact/family applicability and scoped field locks; references immutable profile revision; no overwrite of existing revision | G1: precedence, per-model meaning, temporary exception and compatibility |
| P3 ApprovedExperimentConstraints | **LearningExperimentStore extension** | Constraints/locks frozen with exact experiment snapshot and approval identity; immutable approved revision | G1/G3: changing a constraint invalidates consent and creates a new approved snapshot; no in-place historical rewrite |
| P4 CampaignPlanRevision | **LearningExperimentStore proposed campaign-document namespace** | Campaign ID/revision, bounded plan and template references, experiment IDs/dependency intent; no runnable NJR copies or job status cache as truth | G3: campaign metadata scope/version/retention and plan validation |
| P5 CampaignApprovalRecord | **Same proposed LearningExperimentStore campaign namespace** | Operator approval bound to plan digest, exact envelope/bounds, expiry and eligible resource/evaluator identities; revocation history | G3/G4: authority/expiry/material deviation/eligibility policy; no inherited permission from ordinary profile/save |
| P6 CampaignSubmissionIntent | **Same proposed LearningExperimentStore campaign namespace** | Pause/resume/stop-future-admission intent, generation/checkpoint, reserved exact NJR IDs and canonical association refs | G3/G4: serializing reservation, pause races and cross-store reconciliation; never a second runnable queue |
| P7 CollectionDispositionMetadata | **Proposed LibraryMetadataStore** | Source-namespaced asset references, collections/tags/favorites and disposition intent; no job records/results or duplicated lifecycle | G5: dependency policy, archive vs remove vs delete, trust/retention/import; store **not approved** |
| P8 EvaluatorReleaseMetadata | **Proposed EvaluatorMetadataStore** | Evaluator ID/version/hash, rubric/technical-vs-preference task, validation/held-out applicability and rollback references | G6: release authority, sample independence, sufficiency/072, consequences; store **not approved** |
| P9 ResearchImportReceipt | **Proposed ResearchImportMetadataStore** | External namespace/package digest, integrity/trust/comparability findings, dependent/duplicate observation refs | G5/G6: quarantine/import validation and migration/backward compatibility; cannot mint local job identity or qualification; store **not approved** |
| P10 ContinuityReferenceRevision | **StoryboardStore extension** | Versioned reusable continuity metadata and verified linked-media refs, referenced by draft before compilation | G7: continuity/timeline/media semantics and portable trust; no executable state/automatic authority |

No other new durable type is specified by D. In-session browse selections, stale indicators, provenance displays and material-change summaries can remain projections until an approved durability requirement says otherwise. Any later proposal for a store/type not in this register must name its single owner and gate before implementation.

Late A-addendum reconciliation: current `profile_publication` checks context/seed/variant/rating sufficiency **within each experiment**, then pools qualifying samples by setting and ranks means. It does not establish general cross-experiment comparability or principled weighting (D48; addendum A-4). Current Prompt Load route omits a dirty check (D56), and Smart Review's default editor call omits optional lineage (D57); controller backfill/end-to-end impact was not established. These narrow static facts constrain draft/provenance design, not authority to repair them here.
