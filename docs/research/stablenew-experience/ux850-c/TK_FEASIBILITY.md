## Ownership and deferred implementation

GUI code captures intent, measures/reflows widgets and renders projections; toolkit-neutral fit/freshness rules belong in existing view contracts/adapters. Controllers coordinate existing services; they never gain a second compiler, queue, History, cancellation or process manager. No C file is imported by application code.

Model/profile resolution, filesystem scanning/media decode and evidence lookup must use existing services/background query owners and the single dispatcher. Current media revision fencing is a foundation, not proof that all other views already fence late results. Existing async Review/presentation tests (`tests/gui_v2/test_review_async_580.py`, `tests/controller/test_presentation_actions_710.py`, `tests/controller/test_ui_dispatcher_contract.py`) are additional verified future entrypoints.

Navigation/draft scope changes, locking, recovery persistence, a unified catalog, foreign research trust, archive/delete, timeline/branch/continuity, evaluator acceptance and campaign authority remain separate gates. Existing source/test inventory is insufficient for physical DPI/keyboard/screen-reader or generation-quality acceptance. No controller source, ratchet ceiling, test, dependency, settings file, runtime or canonical authority was modified.
